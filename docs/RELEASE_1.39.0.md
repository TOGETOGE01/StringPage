## PDF 转 GP

- 改进 Songsterr 打印谱的品位识别。更准确地读出空弦的 0 品和含 0 的两位数品位，找回被密集数字遮住弦线的谱行。
- 补充无符干全音符、带短符干的附点二分音符和附点休止符的识别，减少把独立符尾判成更短时值的情况。
- 识别小三连音标记和击弦、勾弦的组合弧。跨小节延音会核对前后音符，避免把小节线旁的弧线当作品位或休止符。
- 改进曲末双小节线和空小节的识别，保留尾部的整小节休止。

使用《Jupiter》和《Graze》的原始 PDF 复测。在这两份样本中，71 个和 87 个小节均可直接整谱导出，无需逐小节校对。重新打开 GP 后，验证了三连音、击弦、勾弦、跨小节延音和曲末休止。

## 安装

下载 Release 附件中的 `StringPage-1.39.0.apk`。支持 Android 8.0 及以上，可覆盖安装旧版正式版。可用 `SHA256-1.39.0.txt` 校验下载。
