# 1.17.0：练习位置恢复与小窗口读谱

本版按 2026-11-09 确认的范围，优先修复读谱、声音与谱面同步、手机和平板使用体验。完整 RSE 还原不再作为完成条件；已有采样、弯音及滑音实现保留。

## 练习位置与音源

旧版切换内嵌录音与合成音源会重新建立播放器，丢失当前练习位置和循环；自造双声部 GP 的实际测试中，位置从 12800 tick 回到 1 tick。界面重建也只保存了文件路径，不能恢复所选音源和阅读设置。

现在按同一份文档保存并恢复：显示声部、内嵌/合成音源、练习位置、速度、循环区间、主音量、缩放、五线谱/六线谱和全屏状态。内置练习曲也可恢复，不依赖外部文件 URI。界面重建后保持暂停，不自动出声。状态中只存少量标量，不把整份乐谱或音频写入系统状态 Bundle。

恢复等待新播放器及录音准备完成，并等待有效的总时值；避免就绪通知尚未更新时值时把位置截到开头。合成播放器的实际跳转确认、录音的实际时钟更新到位后，才重新开放播放按钮及空格/媒体播放键。循环设置会同步触发跳转回调，恢复流程在设置任何播放器属性之前登记进行中的目标，避免重复进入恢复操作。

原曲播放中暂停时，读谱引擎默认对齐到当前拍的起点；如果声部正在长休止符内，就会退回数秒。使用提供的《花上亡灵》谱子、Bonus Guitar 声部实际复现过 12 秒退回 10 秒；自造整小节休止符测试也复现 956 毫秒退回零。现在原曲暂停保留 Android 播放器的实际时间，适用于播放按钮、退到后台、失去音频焦点及拔出耳机。连续跳转合并到最后一个目标，避免旧跳转完成回调覆盖新位置。播放中切换音源在暂停完成后才登记待恢复状态，避免旧播放器的回调误消耗新状态。

## 横屏、分屏及字体

旧版 640×360 dp 横屏窗口中，标题和两行播放栏占满高度，乐谱视图实际测量为 1280×0 像素。

布局现在同时考虑可用宽度和高度，扣除系统栏占用。低高度窗口使用紧凑标题和播放栏；更窄或更矮的窗口通过“更多”保留声部、音源和谱面大小入口。小屏调整图标与内边距，标题限定单行，减少控件挤占谱面。屏幕变化依赖 alphaTab 已有的视图重排，不重复加载播放器或手动重绘整份谱子。

## 验证

新增的七项实际 Android 检查已通过（74.290 秒）：长休止符中暂停的实际录音时间；播放中切换音源的位置；两种音源往返后的速度、循环、音量和位置；合成模式界面重建；录音界面重建后的真实 MediaPlayer 位置及暂停；内置练习曲恢复；横屏谱面视口及主要按钮不被裁切。

签名 Release 1.17.0（versionCode 19）在 Android 15 x86_64 模拟器完成完整回归：161 项通过、0 失败、0 跳过（217.168 秒）。本机配置了原有私有参考音色库及 GP8 可选兼容素材，它们不进入 APK 或源码包。

七类窗口各通过一次真实视图检查，并保存、人工核对截图：手机横屏 640×360 dp、竖屏 360×640 dp、小屏 320×568 dp 且字体 130%、紧凑窗口 480×360 dp、分屏尺寸 540×600 dp 且字体 130%、平板竖屏 900×1600 dp 和横屏 1600×900 dp。使用模拟显示尺寸和字体设置验证可用空间，不等同于真实多窗口任务管理或特定厂商系统验收。

检查包括谱面有可见空间、播放/速度/循环及导入/更多按钮完整可见、主要播放文字不被省略、应用名称不折行裁切。在小屏大字体下保留应用图标，省略空间不足的名称；长声部名和次要信息仍可正常省略显示，声部选择框保留完整名称。

另用用户提供的《花上亡灵》GP 文件（96 小节、6 声部）实际打开 Bonus Guitar、切换六线谱并播放内嵌原曲。平板、手机横屏、手机竖屏截图中时间分别推进到 2、7、11 秒，后台返回后保持暂停在 11 秒，不再回退。谱面和主要控制可见，原文件哈希未改变。此项验证窗口变化、播放时钟及后台暂停，不作为整首歌听感或全部同步点组合的等价证明。

## 本轮边界

- 此处恢复依赖系统提供的界面/任务保存状态，不承诺强行停止应用或移除任务后自动重开所有设置。
- 已准备的采样 WAV 仍按原生命周期清理；界面重建后恢复谱面和练习位置，转为合成音源并提示重新准备采样音频，不冒充已经恢复原采样声音。
- 本轮未扩展节拍器、预备拍、练习移调及编辑草稿的跨进程保存。已有编辑/导出功能保留，不作为此次修复的扩展目标。
- 真机暂未连接。模拟器检查不代替小米 Pad 7 Ultra、ARM64、蓝牙输出延迟及真实设备性能验收，也不证明所有 GP 文件或所有复杂反复/同步点组合都正确。
