## PDF 转 GP

- 打印六线谱的弦线太淡、被密集品位打断，或谱行宽度发生变化时，可用 PDF 中的弦线与小节边界找回整行。页面上的斜线也不再容易干扰这类直排谱。
- Guitar Pro 导出的 PDF 可以识别 Times New Roman 等字体排版的品位数字。谱面位置和符干仍参与匹配。
- 补充隐藏重复品位的延音、带括号品位的跨小节全音符，以及终止双线前整小节休止的识别。

用《Jupiter》《Graze》《尼古喵喵》《堕天》《八芒星ダンス》和《サイキック・ブル》的原始 PDF 验证整谱保存与重新打开。六份谱共 667 小节，均无需逐小节校对。

## 安装

下载 Release 附件中的 `StringPage-1.39.2.apk`。支持 Android 8.0 及以上，可覆盖安装旧版正式版。可用 `SHA256-1.39.2.txt` 校验下载。
