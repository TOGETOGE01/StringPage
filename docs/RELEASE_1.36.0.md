## 阅读界面

- 手机页头合并曲名与常用操作，留出更多空间显示乐谱。声部、音源和「谱面」入口并排，谱表样式、缩放和全屏都可从「谱面」调整。
- 平板横屏可独立收起曲库和练习区，弦页会记住布局偏好。手机和平板共用练习面板，窄窗口也能调速、设循环和改节拍。
- 播放栏显示当前小节、播放时间、速度、循环范围与节拍器状态。最近打开的移除操作集中在曲库管理中。

## 跟练和节拍器

- 在练习面板点击「在谱上选段」，然后依次点起止小节即可设置 A/B 循环。谱面和进度条会标出循环范围，也可按小节编号输入。
- 手动滚动浏览时可暂停自动跟随，点击「回到播放位置」恢复。播放到一行末尾时提前留出下一行的阅读空间。触屏编辑点到的音符或品位会描边显示。
- 底部可一键开关节拍器。合成、内嵌原曲、绑定录音及原厂采样播放均支持节拍器。
- BPM 可随乐谱速度变化及练习变速调整，也可固定在 20–300。节奏支持按拍号、二分、四分、八分、八分三连音和十六分音符，节拍器音量可独立调节。

## 安装

在 Release 附件中下载 `StringPage-1.36.0.apk`。支持 Android 8.0 及以上，可覆盖安装在使用相同发布签名的旧版上。`SHA256-1.36.0.txt` 可用于校验下载。
