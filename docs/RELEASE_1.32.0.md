弦页 1.32.0 正式版适用于 Android 8.0 及以上。下载 `StringPage-1.32.0.apk` 即可安装，已有弦页用户可覆盖升级。

### 触屏编辑

- 打开乐谱，点顶部「编辑」，再点五线谱音符或六线谱品位数字，直接修改音高或品位。
- 在音符的「技法」菜单添加或移除闷音、推弦、滑音、击勾弦和泛音等技法。菜单会标出已应用的技法。
- 支持撤销、重做和恢复草稿。通过「导出 GP 兼容副本」把修改保存为独立文件。

### 本次正式版的其他更新

- 新建乐谱，编辑轨道、独立声部和小节。支持用 MIDI 键盘逐拍输入单音或和弦。
- 导入本地录音后，可用波形查看并校准同步点。
- 新增 WAV 合成混音和打印版 PDF 导出。
- 更新手机和平板的读谱界面、更多菜单和吉他效果器界面。

已在 Android 模拟器上验证手机竖屏与平板横屏的触屏编辑。小米 Pad 7 Ultra 真机及外接 USB MIDI 键盘待实测。GP 兼容副本按当前乐谱模型生成，建议保留原文件。
