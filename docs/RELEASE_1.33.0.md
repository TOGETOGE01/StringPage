弦页 1.33.0 正式版适用于 Android 8.0 及以上。下载 `StringPage-1.33.0.apk` 即可安装，已有正式版用户可覆盖升级。

### 吉他效果器

- 新增 14 套音色，现有 20 套内置预设，按清音、过载与失真、高增益、调制与空间分组。从「更多 → 吉他效果器 → 套用预设」试听。
- 新增明亮清音和暖调清音音箱、小型 1×10 与半开放式 2×12 箱体，以及法兹踏板。
- 新增立体声颤音、镶边、磁带风格延迟、左右交替延迟及弹簧风格混响。调制可放在音箱之前、效果环路或箱体之后。

### 乐谱与歌词

- 修复同一份 GP 混用逐拍歌词和声部歌词时，部分歌词可能漏显示的问题。声部列表会标出带歌词的声部。
- 移除内置练习曲及其入口。打开弦页后可导入自己的 GP 谱或新建乐谱。
