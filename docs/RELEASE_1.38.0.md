## PDF 转 GP

- 改进 Songsterr 打印谱的识别。利用 PDF 里的绘图轮廓区分品位数字、括号和小节线，读出常见的 BPM、拍号、整小节休止和延音。
- 标记有漏读迹象的指法。小节时值校验通过后，仍会保留未确认的指法和技法提示，直到按原谱确认。
- 点击原谱的小节可直接打开校对窗口。待校对小节可单独试听已识别的音符，推荐片段优先选有音符的连续段。
- 封面及识别失败的页可以跳过。后续正常谱页可继续转换，跨缺页的范围会提示分段导出。
- 重新打开同一份 PDF 时会恢复已应用的校对、速度和选段。从 PDF 试听页导出 GP 会保留原有的普通 GP 恢复草稿。

用《Jupiter》原稿复测，71 个小节中有 51 个无需逐小节校对。第 22–24 小节已导出并重新打开，验证第 24 小节的三个延音均已保留。
