# 1.15.0：谱内自定义滑音参数

本版仍以读谱、听谱、跟练为范围。新增参数作用于“原厂采样 · 按谱播放”，不改写原始 GP 文件，也不改变内嵌原曲。

原有默认滑音实现只采用固定时长和距离。现在从原始 GPIF Note 的 XProperties 读取以下字段，贯穿逐音源信息绑定、私有模型快照、滑音生成及实际播放事件。

| 参数 ID | 含义 | 默认值 |
|---|---|---|
| 688066569 | 滑入起点比例 | 0.8 |
| 688066570 | 滑入中间控制值 | 0.4 |
| 688066571 | 滑入距离 | 3 半音 |
| 688066572 | 滑入预留时长 | 240 native tick |
| 688066573 | 滑出起点比例 | 0.8 |
| 688066574 | 滑出中间控制值 | 0.4 |
| 688066575 | 滑出额外距离 | 3 半音 |

native 时钟为每四分音符 480 tick。滑出上/下行距离在第一个半音之外叠加额外距离，默认总范围为 4 半音。中间控制值被保留；受测桌面版的整数音高、时间向量生成器只使用端点，因此本版没有给它们额外编造曲线效果。

延音链的滑出标记、节奏来自尾音，自定义属性仍从原始根音读取。这一行为已在根音/尾音使用不同参数的对照中验证。向空弦以下滑动的距离限制、采样起点、淡入淡出及过渡音品位沿用既有原版对照结果。

数值处理区分 Int、Float、Double、String、Bool：数值节点按原版的 C 前缀转换，字符串值使用完整字符串转换。浮点转整数保留该桌面版本的溢出返回值。常规缺省值、首个元素、重复有效属性与模型快照传递都经过检查。

## 实装验证

签名 Release 1.15.0（versionCode 17）覆盖安装于 Android 15 x86_64 模拟器，全套 143 项测试通过，0 失败、0 跳过（161.736 秒）。包含私有参考音色库实际生成 WAV、自定义滑入在书面首音之前产生声音、实际 MediaPlayer 跳转/重播与谱面时钟检查，以及 GP8 内嵌 OGG 检查。参考库和产生的商业采样音频不进入 APK 或源码包。

初次全套测试和随后一次单测曾出现“回到开头后音频时钟不前进”，当时模拟器与桌面模块分析同时运行；重启模拟器、关闭分析进程后，单测及上述全套测试均通过。尚不能由这些结果确认停滞的根因；失败记录保留在私有验证目录，没有靠放宽断言或修改生产播放逻辑消除失败。

## 边界

完整 RSE 仍未还原。普通音符的原生微时序、完整弯音/泛音/颤音组合、所有动态幅度函数、拾音器混合、音箱/效果链、最终音频等价和小米 Pad 7 Ultra / ARM64 真机验收仍在剩余范围内。

额外探针发现本机 Core 对“同一属性重复且后项无值/无效”的个别组合存在不一致的属性表行为。当前兼容策略保留已读取的有效值；本版没有把这种异常组合宣称为逐位等价。生成音段和音频总长度仍有分配上限，异常的超大参数不会无限分配内存。

导出或重写 GP 仍受 alphaTab 序列化范围约束；本轮保证原始文件读取与播放快照中的参数传递，不保证第三方扩展字段在所有导出格式中往返保留。
