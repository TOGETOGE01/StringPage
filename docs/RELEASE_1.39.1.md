## PDF 转 GP

- 对识别不完整的打印六线谱，自动换用其他渲染尺寸重扫。确认小节边界、时值、已识别品位和跨小节延音一致后，采用完整的识别结果。
- 根据谱线、品位轮廓和符干识别打印版式，兼容另存或转发时丢失内嵌标题的 PDF。
- 用《Graze》和《Jupiter》验证整份转换、保存 GP 和重新打开。原始 PDF 和去掉内嵌标题的副本均可整谱导出，分别为 87 和 71 小节，均无需逐小节校对。

## 安装

下载 Release 附件中的 `StringPage-1.39.1.apk`。支持 Android 8.0 及以上，可覆盖安装旧版正式版。可用 `SHA256-1.39.1.txt` 校验下载。
