## PDF 转 GP

- 缺少 BPM、调弦或起始拍号时，页面会列出可一次应用的建议，保留已识别的设置。100 BPM 是试听参考。缺少起始拍号的乐谱会暂按 4/4 预览，由用户确认后导出。
- 有小节待校对时，可以一键跳到对应小节，也可以选用最长的可导出连续段，免去手填起止编号。
- 校对窗口会显示原谱片段和时值检查结果。可以点选时值，确认原谱末尾有休止时也可一键补齐。复杂指法和技法仍可通过高级文本编辑修改。
- 「保存 GP」会说明还缺哪些设置或哪些小节需要修正。取消保存、写入失败和保存成功都有明确反馈，写入失败后可重新选位置重试。

## 安装

下载 Release 附件中的 `StringPage-1.37.0.apk`。支持 Android 8.0 及以上，沿用弦页正式版的发布签名。可用 `SHA256-1.37.0.txt` 校验下载。
