# 弦页 Android

本地 Guitar Pro 乐谱阅读器，支持 GP8 内嵌 Audio Track 播放与同步跟谱。界面优先适配小米 Pad 7 Ultra，同时支持手机、竖屏和分屏窗口。

当前目标限定为读谱、听谱与跟练，完整 RSE 播放还原继续推进；制谱与出版功能不再作为完成条件。具体范围见 [PRODUCT_SCOPE.md](../PRODUCT_SCOPE.md)。以下使用说明记录 1.14.0 能力及限制。

## 安装与使用

1. 将交付的 `StringPage-1.14.0.apk` 传到安卓设备安装。最低 Android 8.0；平板建议 Android 15 或更新版本。
2. 点击“导入”，通过系统文件选择器打开 GP 文件。支持一次多选；通常长按第一份文件，再勾选其他文件。无需授予整个存储空间的访问权限。
3. 如果文件内含可读取的音频，会显示“内嵌原曲”；没有内嵌音频时，界面明确提示并使用合成音源。
4. 点击“播放”。点击谱面可跳转；进度条、速度和小节循环均可操作。
5. 点击音源按钮，可在内嵌录音与按谱合成之间切换。
6. “更多 → 混音与练习设置”提供合成声部音量、静音、独奏、播放移调、节拍器和一小节预备拍。完整录音没有可独立控制的乐器声部，此时提供切换合成音源的入口。
7. 选择小节循环后，“更多 → 逐轮加速练习”设置起始/目标速度、增幅和重复轮数。到达目标后保持；手动变速、关闭循环或切换音源会停止加速。
8. “基础编辑”支持曲名、作者和已有弦乐音符的品位；延音链一并修改。不支持新增音符、时值、和弦、技法或完整制谱。支持最多 20 步撤销/重做；一次混音弹窗操作合为一步。
9. “导出 GP 兼容副本 / MIDI”通过系统选择位置写入新文件。GP 是当前模型重新生成的 GP7/8 文件，保留可读的内嵌录音与同步点，但不保证原文件无损往返。导出前显示具体限制。MIDI 不含录音、RSE 或临时练习设置，静音轨道不写入 MIDI。
10. 编辑后异步保存本机恢复草稿；重新启动可选择恢复。草稿与 GP 兼容导出具有相同的数据范围，不能替代原文件。退出或切换文件会提示未导出修改。极快退出或系统在写入前终止进程，仍可能丢失最后一次操作。

可先打开“内置练习曲”，检查设备上的谱面显示与内嵌 WAV 播放。内置练习曲及音频为本项目生成的原创测试内容。

## 批量导入与最近打开

- 多选时逐份校验 GP/GTP/GP3/GP4/GP5/GPX，显示进度并可取消。损坏、不支持或超过 128 MB 的文件单独报告，不影响其余文件。取消时保留本批已校验完成的记录。
- 同一 URI 重复导入会更新记录，不生成重复项。取消了原来的 12 条上限；侧栏只预览前 8 条，其余保存在“查看全部”和顶部“最近”的管理窗口中。
- 批量导入不会替换当前打开的乐谱，也不丢弃未导出的修改；当前为空时打开第一份成功导入的乐谱。
- 点击侧栏“最近打开”标题可折叠或展开，状态自动记住。标题旁的更多按钮进入管理窗口；手机通过顶部“最近”进入。
- 管理窗口支持按曲名或文件名搜索、逐条移除、批量移除和清空。**这些操作仅移除应用内记录，不删除原始 GP 文件，也不关闭当前乐谱。** 被移除条目不再作为恢复指针。
- 使用系统文档提供器授予的持久读取权限；如果提供器只允许临时访问，会在批量导入结果中提示，重启后可能需要重新选择该文件。记录仍指向源文件，不是把所有谱子复制到私有曲库，源文件移动、删除或撤销授权后需要重新导入。

## 原厂采样按谱播放（1.14）

导入音色库后，打开乐谱，点击“音源 → 原厂采样 · 按谱播放”，为参与播放的声部分配音色库。鼓组按击打音分别分配；已静音的声部不参与准备。可以设置±12半音移调，鼓组不移调。点击“准备播放”，完成后使用原有的播放/暂停、谱面跳转、进度、保持音高的速度调节及小节循环。

准备过程展开反复段、速度变化、延音与已有MIDI弯音事件，再混合所选原厂采样。按谱播放的音频临时保存在应用私有缓存，不修改GP文件里的原曲和同步点。单次生成音频上限256 MB，过程可取消；正常换谱、切换音源或销毁页面时删除，新进程首次打开页面时清理上次遗留的准备文件。更改声部混音、音符或音色库后需要重新准备；当前轨道混音、节拍器、预备拍和逐轮加速仍通过GeneralUser模式设置或使用。

**原厂采样已接入乐谱播放，完整RSE仍未还原完成。** 1.8将真正RSE的音色库解析、树查找和缺样回退接入实际播放，替换原来的路径打分选样；修正力度、泛音采样音高及品位、同拾音位置重复波形，以及末个Wave的移调/幅度修正。350库共11,387个采样元数据和923,240次原生查找已完成对照；等距离候选使用谱库顺序，不能复制桌面进程的堆地址排序。

GP6/GP7/GP8额外读取演奏风格与打击乐RSE定义，读取失败会阻止原厂采样准备，普通读谱仍可使用。演奏风格按照原程序规则影响指弹、交替拨片和slap选样；明确的拨片方向、slap/pop和泛音随后覆盖。特殊调弦、定制skill、自定义打击乐歧义和全部技法解释器仍未等价。无法匹配或未完整处理的音符会在准备结果提示替代数量。

默认释放使用原生128帧衰减，实际采样回归验证其后静音。1.9另接入原生起音包络和保留相位/历史的32帧重采样器：降调三次插值、近1倍线性及两档升调滤波。原程序1,344个起音块、1,920个重采样块数值逐位对照；另验证单/双声道、缓存跨块、循环和移调修正。修正值从限制后的目标移调中扣除，避免原先符号相反。

按谱播放仍使用自己的事件分块；完整原生tick、剩余连奏/滑音组合、全部技法包络、拾音器混合、音箱与效果链尚未完成。非44.1kHz的源音频现在独立转换到44.1kHz，再进入音符移调，详见下文。固定输出余量、MIDI音量/表情等仍含兼容策略，不代表整条音频与桌面相同。单音库预览仍为独立试听器。

1.10将普通重音、强重音和模型保留的弱音先作用于请求力度，再选样并按原生力度差函数补偿，不再把MIDI velocity线性缩放当作RSE力度曲线。解码前增益、末Wave的ratio和音符增益在各自阶段应用，保留0.3的应用输出余量，完整混音校准尚未完成。

1.12从原始GPIF引用图关联每一个音符，保留组合Accent标志、AntiAccent及逐音点弦/击勾弦标记；不依赖自动生成的音符ID，也不把整拍tap当作和弦所有音的原始标记。实际选样优先使用原谱重音：强重音优先于普通重音，Soft/Normal弱音减一级、Strong减两级。支持GP6原始/压缩容器、多轨多谱表和弯音辅助音；映射不一致时阻止原厂采样准备。

1.13将击勾弦、左手点弦和点弦接入实际按谱播放：同弦前音取紧邻前一拍，不跨越休止或换弦寻找；勾弦力度系数0.7、击弦0.8，左手点弦独立使用0.8。按原版顺序先处理击勾弦、后处理点弦覆盖起点；力度修饰占用原版槽1/2，力度差补偿占槽7，按槽序进行float32乘算。435组真实Core音符及原版解释器对照覆盖和弦、多声部、跨小节与组合标记；184组真实GPIFReader布尔对照覆盖重复属性、大小写、空白、CDATA和注释边界。实际准备WAV验证了起点跳过和左手点弦幅度。该版本尚未还原其他解释器对这些技法的后续覆盖与完整过渡调度；旧GP格式丢失的和弦内逐音点弦歧义仍计入替代提示。

Eastern钢琴40个高音区采样按照原厂AudioStream规则关闭循环，按谱播放和单音试听同时生效；元数据查看器仍显示文件原本的循环记录。已对原库120个实际AudioStream逐项核对。

1.14接入弦乐默认滑音的实际音段生成：移位滑音、连滑、上/下滑入和上/下滑出按半音生成采样音段，分别设置512帧包络及1024/15000帧起点，并受采样循环起点上限约束。保留原始Slide组合标记，按原版错误位处理同品、缺少目标和空弦条件，沿延音链处理末音滑音。原版480 tick/拍与谱面960 tick/拍明确换算；生成音保留根音品位坐标，只改变目标MIDI。滑音之后的断奏/极短断奏只改变原音范围，已生成的过渡段保持原范围。

964组真实Core/RSE自动化图、864对向量、80组标记读取、56组滑音与断奏顺序及192组起点对照通过；涵盖延音、附点、三连音和七连音。开头滑入保留实际预留时间，同步映射对齐谱面，跳回第一拍会重播滑入。真实采样WAV和实际安卓播放器的音频时钟、跳转及重播已回归。准备时只在私有快照中移除MIDI滑音曲线，保留其他演奏信息，不修改原谱；快照不复制内嵌录音，原录音继续保留。长延音链使用迭代缓存处理。

当前滑音使用已验证的原版默认范围和时间参数。整体时序仍通过现有MIDI派生事件适配；自定义滑音参数、完整弯音/泛音等技法组合、时变幅度修饰和全部原生调度尚未等价。部分复杂组合计入替代技法提示，完整声音一致仍未达成。

1.11接入与原版对照匹配的MIT开源r8brain 1.6转换器：原始PCM先单独转换到44.1kHz，再应用解码增益、音符重采样和后续增益，不再把源采样率混进移调倍率。按谱播放与单音试听均使用该阶段；转换支持取消并限制输出PCM大小。32组自造有限长度源流、320,642个浮点样本与原版对照，安卓x86_64重放逐位一致；112组流长度函数对照通过。1.13用真实AudioStream验证后，修正了之前未经调用链证明的循环换算：原版直接保存循环坐标，PCM长度转换不适用于这些字段。Vorbis仍由Android MediaCodec解码，该模块一致不等于商业采样解码PCM或完整RSE一致；ARM64真机仍待验收。

兼容GP导出与恢复草稿保留原谱演奏风格，包括缺省值；不会再由GM音色推测后改成拨片。导出ZIP统一重新计算标准CRC，内嵌录音字节保持一致；其余RSE预设、效果与打击乐定义仍不保证无损保存。

1.7已接入独立移植的AMAudio音量/声像块处理器：每个声道分别保留平滑状态，同一声道的音符先混合再处理，声像变化按块渐变。344个连续原DLL处理块、31,673个样本的本机重演逐位一致；安卓另以浮点误差容限对照。MIDI音量/表情仍为独立线性控制，事件分块时序与桌面不完全相同，不能据此宣称整条RSE音频等价。

延音循环在原库记录的end帧之前回到start，使用独占结束边界。1.13对真实Vorbis解码器与AudioStream完成26组44.1k/96k对照：解码器只接受严格小写`cue`键，重复时以后者为准；实际AudioStream构造后的查询还存在已记录的排序状态问题。按谱播放使用实测的流查询结果、原版默认4000帧起点回退及loopStart上限，无循环时上限为0，关闭延音循环仍保留该上限。元数据查看器继续宽松显示原始记录，不用TAP/LEGATO文字标签推测起点。完整原生tick和其他技法过渡仍待完成。

## 音色库管理与单音试听

“更多 → 原厂音色库 · 采样预览”支持导入一个或多个 `.gp7bank`，自动去重，选择实际录音采样和拾音位置，移调试听，并读取原库的延音循环。试听保持原有单声道或立体声；切到后台、关闭弹窗、失去音频焦点或拔掉耳机时停止。移除操作只删除应用内副本。单库上限128 MB，已导入总量上限2 GB。APK不内置原厂商业采样，需要自行提供音色库文件。

默认合成模式仍为GeneralUser GS；原厂采样播放需要主动选择并准备。选样树与音色库解析已接入真正RSE规则；全部上层演奏状态、过渡与声音等价仍需验证。

引擎基础模块另含318项效果参数转换、29,303对原精度浮点值；Kotlin实现与119,124次原DLL调用逐位对照通过。其行为是阶梯查找，不是插值；保留原始数值ID和负无穷端点。这个模块只转换参数，不处理声音，也尚未绑定GP预设。二进制资源`rse-effect-parameters.bin`仅含数值表，不含原DLL代码或录音。

独立Kotlin文件读取器已对本机350个音色库的全部索引、11,390个采样描述、15,188个音频头验证通过。非标准LIST元数据保留诊断，不猜测缺失标签。只支持已验证的AMARCHIVE v1；不校验Ogg CRC，音频解码由系统解码器进一步校验；单次解码PCM上限32 MB。格式读取成功不代表音频解码或声音等价。

## 平板布局

1.2 更新界面：浅色导航与文件侧栏、白色谱面阅读区、分组练习卡片，以及独立的深色播放栏。平板将曲名信息和常用工具并排，手机自动改为两行；窄屏隐藏冗余图标。播放/暂停、音源、当前声部和选中速度均提供明确状态。弹窗根据内容和屏幕高度收缩，曲名与声部名过长时省略显示。未新增宣传标语。

- 宽度不少于 1200 dp：左侧文件与声部、中间谱面、右侧练习控制。
- 840–1199 dp：保留左侧文件与声部，练习操作在底部及弹窗中提供。
- 小于 840 dp：单栏谱面，文件、声部和练习操作通过按钮打开。
- 横竖屏和窗口尺寸变化时重新排版，不重建音频播放器。
- “全屏看谱”收起侧栏和谱名区域，保留播放控制。
- 支持五线谱、六线谱、组合显示，以及多档缩放。窄屏设备通过“谱面”菜单切换谱表类型。
- 键盘空格：播放/暂停；Home：回到开头。编辑小节数字时保留正常输入行为。

测试目标视口为 3200 × 2136 与 2136 × 3200，模拟器逻辑密度为 320 dpi。该测试用于检查 Pad 7 Ultra 尺寸和比例下的布局；不等同于小米真机或 HyperOS 认证。

## 音频与格式范围

- 乐谱解析由 alphaTab 1.8.4 提供，支持 `.gp3`、`.gp4`、`.gp5`、`.gpx`、`.gp`。
- GP8 的内嵌录音经解析后临时写入应用私有缓存，由 Android MediaPlayer 解码播放；原 GP 文件保持原样。
- 使用文件中的同步点将录音时间映射到谱面，支持原有速度变化及反复段信息。
- 没有同步点的录音仍可播放，但跟谱准确度取决于文件内容。
- 只有外部音频引用的 GP 文件不能凭空获得录音，需要在 Guitar Pro 中勾选嵌入音频后重新保存。
- 真实录音与合成演奏分别播放；选择声部只改变谱面，不会将完整录音拆成单独乐器。
- 1.4 默认合成音色改为 GeneralUser GS SoftSynth 1.44（约 31 MB），替换原先约 1.35 MB 的 SONiVOX GM 小库。已包含完整原始许可证和作者信息；合成器仍为 alphaTab/TinySoundFont，不是 Guitar Pro RSE。
- 原厂采样模式已能按谱播放，但完整RSE技法/力度/连奏及拾音器、音箱、效果链仍未等价还原。GeneralUser模式仍不支持完整SoundFont modulators、chorus/reverb sends。
- 实测内嵌 WAV 与 OGG；其他音频编码的可播放性取决于设备解码器。
- 单个导入文件最大 128 MB。应用提供有限基础编辑，不提供完整制谱、音频分离、自动扒谱或在线曲库。
- 切换到其他应用、失去音频焦点或拔掉耳机时暂停，播放时保持屏幕点亮。

## 构建

用 Android Studio 打开本目录，安装 Android SDK 36。使用 JDK 17 或 21。
原生采样率转换模块另需 Android NDK 28.2.13676358 和 CMake 3.22.1；构建包含 arm64-v8a、armeabi-v7a、x86、x86_64 四种架构，并使用16KB ELF段对齐。

```powershell
.\gradlew.bat assembleDebug
.\gradlew.bat lintDebug
.\gradlew.bat connectedDebugAndroidTest
```

日常测试使用内置原创练习曲，无需外部资源。可选的真实 GP8/OGG 兼容性测试需要先运行：

```powershell
.\tools\fetch-test-fixture.ps1
.\gradlew.bat connectedDebugAndroidTest
```

该脚本从 alphaTab 上游下载测试文件，文件仅用于本机兼容性验证，不包含在交付 APK 或源码压缩包内。源地址见脚本。

原厂采样的实际解码、准备和播放测试另需给debug应用的`files/rse-reference.gp7bank`提供本机参考库。本轮验证使用12-Steel库；该文件不在应用/测试APK和源码包内，未提供时相关测试明确跳过。测试源码与原版数值语料随项目提供，运行安卓测试无需加载Windows DLL；本仓库保留安卓实现及数值回归语料，不包含本机逆向工具、桌面二进制或分析工作目录。
