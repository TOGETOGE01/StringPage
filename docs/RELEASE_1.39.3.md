## PDF 转 GP

- 导入带 90°、180°、270° 页面旋转设置的电子六线谱时，保留可直接读取的音符信息，并让转换预览与识别位置对齐。
- 改进纯图片六线谱的粗体品位、两位数品位、附点休止和延音弧识别。较淡的外侧弦线可结合完整小节线恢复，空小节会在确认谱线完整且无节奏标记后读成整小节休止。

将《Jupiter》《サイキック・ブル》和《八芒星ダンス》设为不同的页面方向后重新导入，共 311 个小节通过整谱导出和重新打开验证。纯图片版的识别也有改善，仍可能出现需要校对的小节。

## 安装

下载 Release 附件中的 `StringPage-1.39.3.apk`。支持 Android 8.0 及以上，可覆盖安装旧版正式版。可用 `SHA256-1.39.3.txt` 校验下载。
