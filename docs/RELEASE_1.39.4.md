## PDF 转 GP

- 改进纯图片六线谱的两位数品位、有圈的二分音符、闷击和弦及符干配对，减少将符干残影当成品位的情况。
- 增加扫描谱的轻揉弦、宽揉弦、滑出和人工泛音识别。人工泛音会读取标出的触弦位置，也支持沿虚线延续的标记。
- 改进掌根闷音（P.M.）、推弦和击勾弦的识别。在多次重扫的结果一致时，可自动恢复部分漏识别的小节线。

## 验证范围

《Graze》和《Jupiter》的纯图片版在两种扫描分辨率下均通过整谱识别、GP 导出和回读，共 158 小节。复杂扫描件仍可能出现需校对的小节，尤其是多个技法重叠、品位不清晰或节奏符号相连时。遇到提示可按原谱核对后再保存。

## 安装

下载 Release 附件中的 `StringPage-1.39.4.apk`。支持 Android 8.0 及以上，沿用旧版正式版签名，可覆盖安装。可用 `SHA256-1.39.4.txt` 校验下载。
