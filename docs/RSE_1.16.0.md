# 1.16.0：原版弯音曲线进入采样播放

本版继续以读谱、听谱和跟练为范围。完整 RSE 尚未完成，不能把本版的曲线及音频检查理解为与桌面版整条声音等价。

## 处理行为

从原始 GPIF 读取逐音 Bended 标记和七个弯音字段，保留缺省值、首个 Float 节点及数值前缀读取行为。Bended 的 Enable 子元素表示启用，其文本内容不是普通布尔开关。数值仍使用 GP 单位：50 为一个半音，偏移按百分比记录。

计算有效字段时遵循受测 Core 的规则：延音音符的起点根据前音延续；未设置的中间值取起点与终点的平均值；未设置的终点取起点。有效性修正使用原版的整数音高分组规则，而不是直接比较三个原始浮点值。保持、单向弯音、预弯后继续、回落及弯起再回落分别生成常量或线性曲线。

原版的插值参数为整数 native tick，每四分音符 480 tick。线性曲线使用 tick/(总 tick−1)，处理一个 tick、负位置、重复控制点及非单调偏移的规则均有实际对照。延音链没有新弯音时可继续当前曲线；后续弯音重新分段。未弯音的滑音、击勾弦起点、揉弦会成为 bend stopper，终止当前变化并保持对应音高。

断奏按原版解释器顺序在弯音之后处理：缩短发声结束位置，不把弯音曲线压缩到缩短后的时长。与已实现滑音共同出现时保留逐音曲线；所有组合的端到端声音仍待进一步对照。

## 接入声音

准备播放时创建私有 Score 快照，转移原始逐音信息，清除已替换的 MIDI 弯音及相关模型链接，再生成逐音演奏事件。原始 Score、谱面弯音和内嵌音频保持不变。

FactoryScoreRenderer 将弯音曲线绑定到各自采样声音。NativeSampleVoice 在 32 帧重采样缓存补充时读取当前 native tick 的音高调制；缓存中已有的声音继续按原状态输出。弯音与其他音高来源相加后执行原版范围限制，再应用采样本身的音高校正。音量、声像处理仍使用现有渲染块，不因弯音额外拆分混音块。

RseBendClock 将现有演奏时钟映射到 native tick，并使用与音频渲染器相同的采样帧取整顺序，支持谱内速度变化处的时刻换算。它仍是现有时钟的适配层，未替代完整 AudioCore 原生调度器。

- GPRSE.dll SHA-256：`f004d24e65c4ea4ba1d82fcc991417e7abddd7ece402358b92c8f906dab4e4d9`。
- GPCore.dll SHA-256：`053e31d8c78b052198918cdd16e0af91e2631daa2c08d7b2db2d93d69d040d81`。
- 90 组实际控制点、1080 个实际插值数值。
- 160 组单音原始 GPIF 和 23 组延音链，共 183 组实际生成图；包含缺省、数值前缀、低幅弯音、有效性修正、延音、stopper 和有符号零的输出处理。
- 12 组原版 Bend→Staccato，覆盖四分、八分、附点和三连音。
- 7 组原版 Bend→HoPo/Tap→Slide 图，覆盖六个单独滑音标记和组合标记；实际生成的 20 个子音段均继承同一个弯音函数，数值一致。这验证了子音段的曲线归属，未代表所有技法组合的最终声音等价。

公开测试夹具仅含自造 GPIF、数值和模块哈希，不包含桌面 DLL、反编译文本、商业音色库或商业采样音频。

## 采样音频的播放控制

RSE 准备出的音频与内嵌录音共用实际 MediaPlayer 播放路径。本轮发现并修复三个可独立复现的生命周期问题：

- 暂停时设置 PlaybackParams 会启动底层播放器，立即再暂停也会移动实际时钟。80 次暂停变速曾使位置从 0 前移至 636 毫秒；现在暂停时缓存速度，播放时再应用。
- 底层播放器短暂报告未播放后，原来的位置轮询会永久退出。真实音频已到 710 毫秒时，跟谱位置仍停在 203 毫秒；现在以控制器请求的播放状态维持更新，并在通知后检查播放器是否已释放或替换。
- 播放器确实到达文件末尾后，循环仅跳转会停在 0 毫秒。现在跳转完成后按请求状态恢复播放；如果控制器已经暂停或释放，则不会重新启动。旧播放器的回调也不能影响新播放器。

回归测试使用本地生成的静音 WAV 和真实 MediaPlayer，分别检查实际位置、速度、跟谱通知及完成后的循环，不引入商业采样。末尾测试明确等待底层不再播放，避免最后一次位置通知提前跳转而绕过完成状态。

## 实装验证

签名 Release 1.16.0（versionCode 18）覆盖安装于 Android 15 x86_64 模拟器：完整回归 154 项通过，0 失败、0 跳过（229.692 秒）；播放专项 9 项通过（92.884 秒）。构建和 Lint 通过，Lint 为 0 错误、49 项警告。

本地验收使用私有参考音色库及可选 GP8/OGG 兼容谱，包含实际准备采样 WAV、一个和弦声部弯音而另一声部保持、暂停变速位置不前移、短暂底层停顿后的时钟更新、文件完成后的重播、小节循环和谱面同步。私有参考库及生成的商业采样 WAV 不进入交付。

此前一轮全套曾出现小节循环起点的时钟停滞，单测及随后带底层位置诊断的全套未再次复现，尚不能把那次偶发停滞完全归因于本次修复。其失败记录保留，原循环断言没有放宽。本轮三个生命周期缺陷分别有真实 MediaPlayer 的修复前失败和修复后通过记录。

## 尚未覆盖或完成的范围

旧格式或缺少可读取原始逐音信息时仍使用既有 MIDI 演奏路径。原演奏事件存在同音来源歧义时，该声部保留原有 MIDI 弯音，避免清除曲线后把它静默变平；恢复这类事件的原始身份仍待完成。

本轮原生弯音的数值对照以列出的自造 GPIF 为范围；跨休止、复杂复声部及所有源音符定位情况尚未穷尽。
